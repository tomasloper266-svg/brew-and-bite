# Brew & Bite — برو آند بايت

موقع مينيو وطلبات لمقهى ومطبخ ولاونج في حمص، سوريا: واجهة زبائن ثنائية اللغة + لوحة تحكم عربية للفريق.

## المميزات

- **واجهة الزبائن**: عربي/إنجليزي (RTL/LTR)، تصفح بالأقسام المصوّرة، بحث وترتيب، صفحة لكل صنف، سلة وطلب (الدفع كاش عند الاستلام)
- **لوحة الفريق** (`/admin/`): متابعة الطلبات الحية مع تحديث تلقائي، بدء التحضير وإنهاء الطلب، إدارة المينيو والأقسام والصور، محتوى الصفحة الرئيسية، والإعدادات
- **الأسعار**: بالليرة السورية مع مكافئ بالدولار عبر سعر صرف قابل للتعديل
- **البيانات**: 15 قسمًا و126 صنفًا مع صورهم، وحالة "غير متوفر حاليًا" للأصناف المنتهية

## التشغيل

```bash
npm install
node server.js   # يعمل على المنفذ 8820
```

- الموقع: `http://localhost:8820`
- لوحة الفريق: `http://localhost:8820/admin/`
- قاعدة البيانات SQLite جاهزة ضمن `data/brew-and-bite.db`، والصور في `data/uploads/`
- أول حساب إداري يُنشأ عند أول إقلاع للخادم — اضبط كلمة المرور عبر متغير البيئة `ADMIN_PASSWORD` قبل أول تشغيل، أو غيّرها من الإعدادات بعد الدخول
- إعادة بناء قاعدة البيانات من ملف المينيو المصدر (اختياري): `node scripts/migrate-menu-data.js` — الترحيل قابل لإعادة التشغيل دون تكرار
- سر الجلسات يُولَّد عشوائيًا ويُحفظ في `data/session-secret.txt` (مستثنى من Git ويُعاد توليده غيابًا)

## البنية

```
server.js                  واجهة Express API + استضافة الملفات الثابتة
public/                    واجهة الزبائن (SPA بدون أدوات بناء)
admin/                     لوحة تحكم الفريق
scripts/migrate-menu-data.js  ترحيل المينيو والصور من البيانات المصدرية
data/                      قاعدة SQLite + الصور المرفوعة
API.md                     توثيق كامل لواجهات البرمجة
```

## التقنيات

Node.js · Express · SQLite (better-sqlite3) · Vanilla HTML/CSS/JS — بدون أي إطار واجهات أو خطوة بناء.
